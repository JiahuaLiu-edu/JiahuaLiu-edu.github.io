最近开始更系统地接触计算机视觉。我一开始很容易被各种模型名称吸引，但真正动手后才发现，最需要补齐的仍然是基础。

这段时间给自己定下的顺序是：先熟悉 Python 和 PyTorch，再理解卷积神经网络的核心结构，然后通过一个小型图像分类任务走完数据处理、训练、验证和复盘的完整流程。

目前最大的收获不是记住了多少网络，而是开始意识到：**能解释实验结果，比单纯跑出一个更高的准确率更重要。**

接下来准备把每次实验中出现的问题留下来，慢慢形成自己的 CV 学习地图。
